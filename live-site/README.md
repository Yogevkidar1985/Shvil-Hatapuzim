# האתר החי — gush6446.netlify.app (גיבוי)

תיקייה זו היא **גיבוי של קבצי האתר החי** (טבלת הקצאה ואיזון · מעקב חתימות · גוש 6446).
האתר מפורסם ב-Netlify בשיטת **Netlify Drop** — גרירת הקבצים ידנית, ללא חיבור Git.

## מבנה
- `index.html` — דף הכניסה (טוען את האפליקציה)
- `assets/index-*.js` / `assets/index-*.css` — ה-build המקורי של האפליקציה (Vite/React)
- `assets/view-enhance.js` — **תוסף בקרת תצוגה** שנוסף: זום (+/-) ורווח בין עמודות (+/-),
  משתלב בסרגל הכלים, שומר העדפות ב-localStorage, ולא נוגע בקוד/בנתוני האפליקציה.

## איך מעדכנים את האתר
1. פתחו את https://app.netlify.com ובחרו את האתר **gush6446**
2. לשונית **Deploys**
3. גררו את **כל תוכן התיקייה הזו** (index.html + תיקיית assets) לאזור הגרירה
4. Netlify מפרסם אוטומטית תוך שניות

> חשוב: לגרור את *שני* הפריטים יחד (הקובץ והתיקייה), לא את תיקיית-האב.
